# TickScope

## 利用開始（Windows / MetaTrader 5）

1. MT5にログインしてから `tick-scope.exe` を起動します。設定ファイルや `mt5` フォルダーの同梱は不要です。
2. TickScopeがMT5のデータフォルダーを検出し、共通EA `TickCollector` と接続設定を配置・コンパイルします。全ブローカー共通の接続ポートを起動時に自動割当てします。
3. MT5のナビゲータを更新し、`エキスパートアドバイザ → TickCollector` を対象銘柄チャートに追加します。EAのID・ホスト・ポート入力はありません。EAはチャート銘柄とMT5口座のサーバー名から接続先を選びます。
4. MT5でローカル接続が許可されていない場合は「ツール → オプション → エキスパートアドバイザ」の許可リストに `127.0.0.1` を追加します。接続できない場合はMT5のエキスパートログを確認してください。

初期設定はOANDA / Axiory / JFXのUSDJPY用です。異なるブローカー・銘柄を使う場合は `config/default.toml` の `brokers` を変更してください。ブローカー名はMT5口座サーバー名の照合にも使われます。同じ銘柄を複数ブローカーで使う場合は、各ブローカー名に口座サーバー名の一部を設定してください。設定ファイルは、起動引数で指定したファイル、実行ファイルと同じ場所の `config/default.toml`、作業ディレクトリの `config/default.toml`、内蔵設定の順で使用します。指定済みの設定に誤りがある場合はエラーになります。

起動ごとにOSが空きポートを1つ割り当て、TickScopeが接続設定を各MT5へ自動配布します。ポート変更時のEA再コンパイルや入力変更は不要です。初回移行時は、チャートに残っている旧EAを外し、ナビゲータを更新して共通の `TickCollector` を追加してください。TickScopeは以前に自動生成したブローカー別EAファイルを `MQL5/Files/TickScope/legacy_broker_eas` へ退避しますが、MT5のチャート上で動作中のEAは手動で一度付け直してください。

標準配置以外のMT5は `[mt5].custom_data_dirs` にデータフォルダーを指定できます。MetaEditorが自動検出できない場合は `TICKSCOPE_METAEDITOR_PATH` に実行ファイルを指定するか、MT5からEAを開いてコンパイルしてください。`[mt5]` の `auto_deploy = false` は自動配置と共通ポートを無効にして、従来の `brokers[].port` に指定した固定ポートを使います。自動接続には `auto_deploy = true` を使用してください。

## 開発

`cargo run` で起動、`cargo test` でテストします。インストール済みMT5への書き込みや稼働中端末を必要とするテストは通常実行から除外されています。
