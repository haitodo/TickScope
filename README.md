# TickScope

TickScope は、MetaTrader 5（MT5）の複数ブローカーから配信されるリアルタイムティックをミリ秒単位で同期・比較・可視化するデスクトップアプリケーション（Rust / egui）です。

各ブローカーの気配値推移（Bid / Ask）、スプレッド差分、先行・遅行関係、ローソク足チャートなどを高速に並列描画します。MT5へのEA自動配置・ポート動的割当・端末プロセス管理機能を備えており、導入から運用までを自動化します。

## 特徴

- **複数ブローカーのリアルタイム比較**: 複数社の気配値やスプレッドの差分、先行遅行をリアルタイムにグラフ化。
- **ゼロコンフィグEA自動配置**: MT5データフォルダーを自動検出し、共通EA `TickCollector` を自動配置・コンパイル。
- **動的ポート割当**: 起動時にOSが空きポートを動的に割り当て、MT5側へ自動配信。ポート競合やEA再コンパイルが不要。
- **MT5端末ライフサイクル管理**: アプリ起動時のMT5一括起動、終了時の一括クローズ、特定ブローカー以外の最小化起動に対応。
- **多彩なチャート & メトリクス**: S1/S5/S10/M1 ローソク足、仲値・スプレッド乖離、気配持続性など 8 種類のメトリクスを瞬時に切替可能。
- **ウィンドウ状態の永続化**: ウィンドウサイズ・位置・最大化状態・最前面固定（Always on Top）を次回起動時へ自動復元。

## クイックスタート（利用開始手順）

### 1. アプリの起動
MT5にログインしている状態で `tick-scope.exe` を起動します。
設定ファイルや `mt5` フォルダーの同梱は不要です。

```powershell
.\tick-scope.exe
```

> **自動配置の仕組み**:
> TickScope 起動時に PC 内の MT5 データフォルダーを自動検出し、共通EA `TickCollector` と接続設定を配置・自動コンパイルします。全ブローカー共通の接続ポートが動的に割り当てられます。

### 2. MT5側の接続許可設定
MT5でローカル通信が許可されていない場合は、MT5メニューの以下を設定します：
- **ツール → オプション → エキスパートアドバイザ** を開く。
- **「WebRequestを許可するURLリスト」** に `http://127.0.0.1` または `127.0.0.1` を追加する。

### 3. チャートにEAを適用
1. MT5の「ナビゲータ」ウィンドウで右クリックして **「更新」** を選択。
2. `エキスパートアドバイザ → TickCollector` を対象銘柄（例: USDJPY）のチャートへドラッグ＆ドロップして適用。
3. パラメータ入力（ID・ホスト・ポート）は不要です。EAがチャート銘柄と口座サーバー名から自動的に接続先を識別します。

## 起動オプション（CLI）

コマンドプロンプトやPowerShell、ショートカットのプロパティから起動引数を指定できます。

### 構文
```text
tick-scope.exe [OPTIONS] [CONFIG_PATH]
```

### オプション一覧

| オプション | 短縮 | デフォルト | 説明 |
| :--- | :---: | :---: | :--- |
| `--console` | `-c` | 無効 | コンソールウィンドウを表示し、テキストログを出力します |
| `--log-level <LVL>` | `-l` | `info` | ログ出力レベルを指定（`error`, `warn`, `info`, `debug`, `trace`） |
| `--diagnostics` | `-d` | 無効 | パイプラインレイテンシの計測を行い、1秒ごとのサマリーを出力・UI表示します |
| `--record-raw` | `-r` | 無効 | 通信プロトコルの生フレームを永続化（`data/logs/` に保存、オフライン解析用） |
| `--config <PATH>` | - | 自動探索 | カスタム設定ファイル（TOML）のパスを指定します |
| `--reset-window` | - | - | ウィンドウサイズ（1100×750）・非最大化・位置を初期状態にリセットします |
| `--version` | `-V` | - | バージョン情報を表示して終了します |
| `--help` | `-h` | - | コマンドラインヘルプを表示して終了します |

### コマンド例

- **コンソールログを表示して起動**:
  ```powershell
  .\tick-scope.exe -c
  ```

- **デバッグログを詳細表示**:
  ```powershell
  .\tick-scope.exe -c -l debug
  ```

- **レイテンシ性能計測と生データ記録を同時に有効化**:
  ```powershell
  .\tick-scope.exe -d -r
  ```

- **ウィンドウサイズや位置がおかしくなった場合に初期化**:
  ```powershell
  .\tick-scope.exe --reset-window
  ```

- **カスタム設定ファイルを指定**:
  ```powershell
  .\tick-scope.exe --config config/my_setup.toml
  # または位置引数で直接指定
  .\tick-scope.exe config/my_setup.toml
  ```

## キーボードショートカット & 操作

| キー | 機能 | 説明 |
| :---: | :--- | :--- |
| `T` | **最前面固定（Always on Top）** | ウィンドウを常に手前に表示。ヘッダーの「📌 Pin」ボタンでも切替可能 |
| `Ctrl + 0` | **画面サイズリセット** | ウィンドウサイズを標準（1100×750）に戻し、最大化を解除 |
| `S` または `,` | **Quick Settings 表示切替** | ローソク足設定、表示業者、MT5プロセス設定ダイアログを開閉 |
| `B` | **Broker Overview 表示切替** | 全ブローカーのステータス・気配値・レイテンシ一覧パネルを開閉 |
| `P` / `Shift + P` | **比較ペアの切り替え** | チャート比較対象となるブローカーペアを順次/逆順に切り替え |
| `1` 〜 `8` | **下段メトリクスの切り替え** | 各種分析指標をダイレクト選択（下記参照） |
| `Tab` / `Shift + Tab` | **下段メトリクスの順次切り替え** | 下段チャートの分析指標を次/前へ循環 |
| `Esc` | **パネルを閉じる** | Quick Settings または Broker Overview を閉じる |

### 下段メトリクス（1〜8キー）
- `1`: **QuotePath**（気配値推移・Bid/Askスプレッド）
- `2`: **MidDiff**（仲値差分）
- `3`: **BidAskDiff**（Bid/Ask差分）
- `4`: **SpreadDiff**（スプレッド差分）
- `5`: **LeadLag**（先行・遅行分析）
- `6`: **MidDispersion**（仲値の乖離度・分散）
- `7`: **MoveBreadth**（値動き幅・モメンタム分布）
- `8`: **QuotePersistence**（気配値の持続性）

## 設定（config/default.toml）

初期設定では `OANDA` / `Axiory` / `JFX` / `Dukascopy` / `Tradeview` の USDJPY 用設定が用意されています。

### 設定ファイルの探索優先順位
1. コマンドライン引数（`--config <PATH>` または 位置引数）
2. 実行ファイルと同じディレクトリの `config/default.toml`
3. カレント作業ディレクトリの `config/default.toml`
4. アプリケーション内蔵のデフォルト設定

### ブローカーの追加・変更例
異なるブローカーや通貨ペアを利用する場合は、設定ファイルの `[[brokers]]` セクションを編集します。

```toml
[[brokers]]
id = 1
name = "OANDA"             # MT5口座サーバー名と照合されるキーワード
host = "127.0.0.1"
symbol = "USDJPY.cl"       # ブローカー側の銘柄記号
point_size = 0.001
pip_size = 0.01
timezone_rule = "ny_close" # NYクローズに連動して夏時間(UTC+3)/冬時間(UTC+2)を自動判定
```

> **ブローカー名の照合ルール**:
> ブローカー名はMT5口座サーバー名（例: `OANDA-Live`, `Axiory-Live` 等）の部分一致で照合されます。同じ銘柄を複数ブローカーで監視する場合は、各 `name` に口座サーバー名に含まれる識別可能な文字列を設定してください。

### MT5設定セクション `[mt5]`
```toml
[mt5]
auto_deploy = true            # EA自動配置・コンパイル・動的ポート割当の有効化
custom_data_dirs = []         # 標準配置以外のMT5データフォルダーがある場合にパスを指定
non_minimized_broker = "OANDA"# 複数MT5起動時、この業者のみ通常表示（他は最小化）
```

- **`auto_deploy = false`**: 自動配置と共通ポート配信を無効化し、従来の `brokers[].port` 固定ポートを使用します。
- **`TICKSCOPE_METAEDITOR_PATH` (環境変数)**: MetaEditorが標準インストール先から自動検出できない場合、MetaEditor実行ファイル（`metaeditor64.exe`）のパスを環境変数に指定できます。

## MT5プロセス管理（自動起動・終了）

TickScope は、監視対象ブローカーの MT5 端末の起動や終了を UI から一括管理できます。

- **自動起動（Auto-Launch）**: TickScope 起動時に、選択した MT5 端末を自動起動します。
- **自動終了（Auto-Close）**: TickScope 終了時に、起動中の MT5 端末を自動クローズします。
- **最小化起動（Launch Minimized）**: チャート監視画面の邪魔にならないよう、MT5 を最小化状態でバックグラウンド起動します。
- **特定業者の通常表示（Normal Window）**: 普段メインで操作・確認するブローカー（例: OANDA）のみ通常ウィンドウで表示し、他の MT5 は最小化しておくことが可能です。

設定は画面右上の「⚙ Settings」→「MT5 Process Lifecycle」、または `B` キーの「Broker Overview」から行えます。設定内容は自動的に保存されます。

## トラブルシューティング

### Q1. MT5からデータが受信できない（DISCONNECTED / WARMING のまま）
- MT5のメニュー「ツール → オプション → エキスパートアドバイザ」で、「WebRequestを許可するURLリスト」に `127.0.0.1` が登録されているか確認してください。
- MT5の「ターミナル → エキスパート」タブを開き、エラーログ（接続拒否、WebRequestエラー等）が出ていないか確認してください。
- チャートに旧バージョンのブローカー別EAが残っている場合は、EAを削除してナビゲータを更新し、`TickCollector` を付け直してください。

### Q2. MetaEditorのコンパイルエラー・自動検出失敗
- MT5が特殊なディレクトリにインストールされている場合、環境変数 `TICKSCOPE_METAEDITOR_PATH` に `metaeditor64.exe` のフルパスを設定するか、MT5のナビゲータから `TickCollector.mq5` を開いて手動でコンパイルしてください。

### Q3. ウィンドウサイズや位置がおかしくなった
- ショートカットキー `Ctrl + 0` を押すか、Settings内の「画面サイズをリセット」をクリックしてください。
- または、`tick-scope.exe --reset-window` で起動すると、ウィンドウサイズ（1100×750）と位置が初期状態に戻ります。

## 開発・ビルド

### 必要環境
- Rust 1.80+（2021 edition）
- Windows 10 / 11

### コマンド
```powershell
# 開発起動
cargo run

# 引数付き開発起動（例: コンソールログ付き）
cargo run -- -c

# リリースビルド
cargo build --release

# テスト実行
cargo test
```

※ インストール済みMT5への書き込みや稼働中端末を必要とする結合テストは、安全のため通常テスト実行から除外されています。
