# TickScope

## 利用開始（Windows / MetaTrader 5）

1. MT5を一度起動してから `tick-scope.exe` を起動します。設定ファイルや `mt5` フォルダーの同梱は不要です。
2. TickScopeがMT5のデータフォルダーを検出し、EAと必要なIncludeを配置・コンパイルします。
3. MT5のナビゲータを更新し、エキスパートアドバイザの `TickScope` 内からブローカー名に対応するEAを、そのブローカーの対象銘柄チャートに追加します。例：`TickCollector_1_OANDA`。ID・ホスト・ポートの入力は不要です。
4. MT5で接続が許可されていない場合は「ツール → オプション → エキスパートアドバイザ」の許可URLに `127.0.0.1` を追加します。接続できない場合はMT5のエキスパートログを確認してください。

初期設定はOANDA / Axiory / JFXのUSDJPY用です。異なるブローカー・銘柄を使う場合は `config/default.toml` の `brokers` を変更してください。設定は、起動引数で指定したファイル、実行ファイルと同じ場所の `config/default.toml`、作業ディレクトリの `config/default.toml`、内蔵設定の順で使用します。指定済みの設定に誤りがある場合はエラーになります。

ポートは設定ファイルからブローカー別EAへ自動反映されます。ポートが他のアプリと競合する場合は設定ファイル側だけを変更し、TickScopeを再起動して、更新されたEAをチャートに追加し直してください（空きポートの自動選択は行いません）。従来の `TickCollector` も手動設定用として利用できます。

標準配置以外のMT5は `[mt5].custom_data_dirs` にデータフォルダーを指定できます。MetaEditorが自動検出できない場合は `TICKSCOPE_METAEDITOR_PATH` に実行ファイルを指定するか、MT5からEAを開いてコンパイルしてください。自動配置を無効にするには `[mt5]` の `auto_deploy = false` を指定します。

## 開発

`cargo run` で起動、`cargo test` でテストします。インストール済みMT5への書き込みや稼働中端末を必要とするテストは通常実行から除外されています。
