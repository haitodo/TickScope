# Implementation Report: A02 (Agent-EA)

## 概要
複数端末（Broker 1, Broker 2, Broker 3...）で共通利用可能なMetaTrader 5 EA (`mt5/TickCollector.mq5`)、プロトコル定義 (`mt5/Include/Protocol.mqh`)、およびソケットクライアント (`mt5/Include/SocketClient.mqh`) を実装完了。

## 主な実装仕様と不変条件の遵守
- **I01 (OnTick != tick count)**: `OnTick` を回収トリガーとして扱い、`CopyTicks(COPY_TICKS_ALL)` で未処理の全出現を回収。
- **I02 (broker_time_msc != unique tick ID)**: 同一ミリ秒内に存在する複数Tickや同内容Tickをハッシュ除去せず、出現順に連番 `sequence` を付与。
- **カーソル管理 (D06)**: `last_time_msc` および同一ms内既処理出現数 `cursor_same_ms_count` を保持。同一msの回収数がバッチサイズを超える場合も動的拡張で前進可能とし、走査上限超過時は明示的に `STATUS_CODE_CURSOR_BLOCKED` を送信。
- **ウォームアップとLIVE (D04)**: 起動時に過去指定秒数（デフォルト60秒）の履歴を `HEADER_FLAG_WARMUP` 付きバッチで送信後、`STATUS(PHASE_LIVE)` を送信して通常配信へ移行。
- **ソケット・ショートライト管理**: 送信未完了のsuffixバッファを保持し、次呼出で送信。再接続時は旧接続のsuffixを破棄しプロトコル整合性を担保。
- **Heartbeat & ACK**: `OnTimer` (250ms) でHeartbeatを送信し、Rust側からのACK (8 byte) をポーリング。
